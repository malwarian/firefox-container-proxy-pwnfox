# Notes to Reviewer

This is a fork of Container Proxy by Aleksey Bekh-Ivanov (BSD 2-Clause). The original copyright notice is in LICENSE and is packaged with the extension. The distinct name and Gecko ID keep this listing separate from the original extension.

The new quick-setup button on the Assign page creates/reuses PwnFox's eight default containers and assigns sequential local HTTP proxy ports (8081–8088 by default). The first port is configurable. All source is unminified in this repository. The fork does not embed PwnFox code.

`data_collection_permissions.required` is `none`: the extension has no telemetry or maintainer-operated endpoint, and proxy assignments stay in Firefox's local storage. The original manual proxy Test button separately asks for confirmation before it makes an IP-check request to DuckDuckGo. The PwnFox quick-setup feature never invokes it. Firefox desktop 142 is the minimum supported version so the built-in data declaration is understood by every supported version.

Build from a clean checkout with Node.js and pnpm 7:

```
pnpm install --frozen-lockfile
pnpm test
pnpm run build
pnpm run lint
pnpm run bundle
```

The last command packages `dist/` into `web-ext-artifacts/`. `dist/` is generated by Webpack from `src/`, and includes the source maps. The extension does not need a server or API key at runtime. For a live check, install the unpacked `dist/` temporarily in Firefox, click the toolbar icon, and use the Configure PwnFox button on the Assign page.

Version 0.1.26 replaces the options page's Mithril/Preact runtime with the small local renderer in `src/options/safe-mithril.ts`. It uses DOM text nodes for text values and does not use `innerHTML`. The Webpack output has an explicit empty `publicPath`, avoiding its dynamic global-object fallback. The Support page links to the fork maintainer's email instead of the original project's Gitter. No third-party library has been modified. The current AMO linter result is 0 errors, 0 warnings, and 0 notices.
